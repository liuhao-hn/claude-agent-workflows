# 申论大作文批改 Skill

模拟高顿AI公考申论批改系统，对用户的大作文进行五维度评分（40分制），输出详细分析和可操作改进建议。

## 工作流程

### Step 1: 获取文章内容

- 若用户发送**文字**：直接使用
- 若用户发送**图片**（手写稿纸照片）：
  1. 将图片复制到 `/tmp/essay_pageN.png`
  2. 使用 Apple Vision 框架 OCR 提取文字（优先用 Swift 调用 VNRecognizeTextRequest，lang=zh-Hans）
  3. 将 OCR 结果整理为完整文章，纠正明显识别错误后用于批改
  4. 如 OCR 效果差，告知用户并请其提供文字版

### Step 2: 获取题目要求

- 若用户同时发送了题目材料/PDF：阅读并提取题目要求和给定材料
- 若用户仅发送文章：根据文章内容反推题目要求，并提示用户"未看到题目，以下评分基于文章本身质量，如有偏差请提供题目"

### Step 3: 回顾批改历史

- 查看 `{批改记录目录}/` 目录下是否有该用户之前的批改记录
- 若有，对比本次与上次的进步/退步，在评分后给出**对比评价**
- 若无，按首次写作对待（评语中给予适当鼓励）

### Step 4: 执行五维度评分

按以下框架逐维度评分，每个维度给出概括和分析（优点+不足）：

#### 评分等级标准
| 等级 | 分数区间 | 核心特征 |
|------|----------|----------|
| 一类文 | 32-40 | 立意深刻、论证严密、素材充分、语言优美、结构严谨 |
| 二类文 | 24-31 | 立意明确、论证通顺、素材合理、语言通顺、结构完整 |
| 三类文 | 16-23 | 立意基本正确、论证基本成立、素材少量、语言基本通顺、结构基本完整 |
| 四类文 | 0-15  | 偏题、论证混乱、素材缺失、语言不通、结构残缺 |

#### 维度1：主题立意（权重约25%）
考察要点：
- 是否直接回应题干核心句子/观点（破题是否精准）
- 核心论点是否明确、深刻、有创新性
- 是否阐述了题目中关键概念之间的辩证关系（如双向互动而非单向）
- 立意是否存在片面性、是否回避了题干的某些关键要素

#### 维度2：论证逻辑（权重约25%）
考察要点：
- 论证路径是否清晰、分论点之间是否有逻辑递进（是什么→为什么→怎么办）
- 每个分论点是否有"观点→阐释→案例→分析总结"的完整闭环
- 段落间过渡是否自然、有无承上启下的过渡句
- 案例与观点的关联是否紧密（是否用案例来论证，而非罗列案例）

#### 维度3：素材运用（权重约20%）
考察要点：
- 是否充分运用给定材料中的案例（覆盖面）
- 材料案例是否有深入分析而非简单罗列（使用深度）
- 是否补充了材料外的合适案例（拓展性）
- 是否运用了正反两方面案例（论证全面性）
- 每个案例是否有效支撑所在段落的分论点

#### 维度4：语言表达（权重约15%）
考察要点：
- 语言是否通顺流畅、符合申论书面语规范
- 是否存在错别字、病句、表述晦涩或歧义
- 表达是否精准，关键概念是否界定清晰
- 是否恰当引用古诗文、名言增添文采（适度而非堆砌）

#### 维度5：结构布局（权重约15%）
考察要点：
- 是否采用"总-分-总"结构
- 开篇是否直接破题（三句话内回应题干核心句子）
- 各段落比例是否均衡（无某段过长或过短）
- 结尾是否有力升华，且与前文论述紧密结合（不突兀）
- 段落间是否有过渡句衔接

### Step 5: 字数检查

- 申论大作文一般要求 1000-1200 字
- 根据答题稿纸格数估算（标准稿纸 25×24=600字/页）
- 明显不足 1000 字：额外扣 2-4 分并在评语中明确指出
- 严重超出 1200 字：提示注意控制篇幅

### Step 7: 输出针对性训练方案

在批改报告末尾，根据本次评分暴露的**最弱维度**，给出一个具体的、可执行的训练方案。格式如下：

```
---

### 四、针对性训练方案

**本次最弱维度：XXX（得分率约XX%）**

#### 专项训练任务

（针对最弱维度设计1个20-30分钟可完成的刻意练习，必须包含：）

**训练目标**：（一句话说明练什么能力）
**训练方法**：（具体步骤，2-4步）
**验收标准**：（怎么判断练到位了）

#### 示例（必须给出）

（给出一个该训练任务的具体完成示例，让用户看到"做成什么样算过关"）
```

**训练方案设计原则：**

1. **一次只攻一个弱点**：只针对本次得分率最低的维度设计训练，不要贪多
2. **20-30分钟可完成**：训练量要适合碎片时间，不要设计"写一篇完整大作文"这种任务
3. **可独立完成**：不依赖外部反馈也能判断自己是否做对
4. **贴近实战**：直接针对申论考试场景，不搞学术化训练

**各维度对应的训练类型参考：**

| 最弱维度 | 可选训练类型 |
|----------|-------------|
| 主题立意 | 同一题目写3个不同角度的开头段+分论点句；或给一篇文章反推其核心立意 |
| 论证逻辑 | 给一个分论点写出完整的"观点→阐释→案例→分析→小结"闭环段落 |
| 素材运用 | 限定1个给定材料案例，写出3层深度分析（事实→原因→意义）；或做正反案例配对练习 |
| 语言表达 | 修改一篇病句/啰嗦段落；或将口语化表达改写为申论书面语 |
| 结构布局 | 给一篇打乱段落顺序的文章重新排序并补过渡句；或写3种不同结尾升华方式 |

### Step 8: 保存批改记录

将完整批改报告保存到 `{批改记录目录}/` 目录：
- 文件名格式：`YYYY-MM-DD_批改记录.md`（如 `2026-07-17_批改记录.md`）
- 若同一天有多篇，加序号：`2026-07-17_批改记录_2.md`
- 记录中应包含：日期、题目、用户原文（OCR整理后）、评分、完整批改报告（含训练方案）

## 评分原则

1. **严格客观**：不过高也不过低。28-30 分已是二类文中上等，不要因为"第一次写"就给到 30+
2. **依据具体**：每个扣分点必须有文章中的具体例证，不能泛泛而谈"论证不够深刻"
3. **建议可操作**：改进建议必须给出修改示例，不能说空话。比如不能说"要提高立意深度"，而要说"在 XX 段落增加 XX 角度的论述，示例：……"
4. **区分首次与多次**：首次写作——鼓励为主+指出方向；多次写作——对比进步+严格挑刺
5. **字数是硬指标**：1000 字以下必须指出并额外扣分
6. **结合实战**：评分要考虑申论考试 70 分钟限时的实际约束，给出的建议要能在考场执行
7. **注意区分：评分 vs 范文**：参考范文通常是 34-36 分的水平，不要拿范文标准来要求考生

## 特别注意

- 本 skill 仅适用于**申论大作文**（最后一道 40 分大作文题），不适用于概括题、分析题、对策题等小题
- 如果用户发送的是小题答案，告知用户本 skill 仅支持大作文批改
- 评分维度权重仅供参考，实际评分应根据文章整体质量综合判断，不要机械套公式
