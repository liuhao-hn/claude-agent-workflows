# 行业库｜路由选材偏好与表达锚点

> 只读**目标岗位对应的一节**。混合岗位选一个主体系，必要时借一个具体表达单元，不整套混用。
> 表达锚点是措辞参考，不能创造或修改事实库中的经历。
> 本节用 `{候选素材}` 标注示例取材方向，需替换为事实库中候选人的真实经历。

## 一、互联网业务型（产品经理 / 运营 / 内容平台 / 电商 / 游戏）

### 选材偏好
- 优先：用户/商家/内容/商品理解、需求分析、运营动作、数据分析驱动决策、产品迭代、跨团队协调
- 示例素材：`{实习中的项目全流程/SOP/数据监控/自动化工具/产研协同}`、`{竞赛中的 Python 数据分析}`、技能池（SQL/数据分析/AI工具）
- 删减：与业务无关的行政细节弱化到 1 条证明"组织协调"；`{无关证书}`通常不写；`{平台深度使用}`只在内容/游戏岗作为理解佐证

### 表达锚点
- 骨架：**准确短标签：问题/任务 + 关键动作/机制 + 最强可信证据**
- 例："数据驱动运营 — 搭建多维度监控体系，追踪产量/质量波动率，定位根因推动迭代，量产合格率提升15%"
- 关键词自然嵌入真实语境，不逐字复制JD
- 主动词优先：搭建、拆解、优化、定位、推动、落地、识别、验证

### 版面注意
- 互联网岗默认不放照片（除非JD/公司风格明确要职业照）
- 技能栏写"能完成什么工作+工具+边界"，不堆软件清单

## 二、财经研究型（银行 / 证券 / 基金 / 人行 / 政策研究）

### 选材偏好
- 优先：行业/公司/政策研究、财务预测与投资判断、数据与计量分析、正式研究材料、风险合规意识
- 示例素材：`{经济学硕士课程（高微/高宏/高计）}`、`{建模竞赛统计建模}`、技能池（SQL/Python/统计建模/经济学分析框架）、`{行政工作体现的严谨细致}`
- 加分：专业工具 Wind/Bloomberg/Capital IQ（只在真会用时写）
- 删减：`{游戏/电商/内容平台理解}`通常不写

### 表达锚点
- 骨架：**业务判断：数据/研究路径 + 结论/用途**
- 例："构建XX指标分析，识别关键驱动因素，输出可解释结论用于XXX决策"
- 强调"研究→判断→落地"链路，数字要经得起追问（10问核查）

### 版面注意
- 银行/国企/传统金融重视职业形象 → 可启用职业照
- 教育背景置顶，课程选2–4门（计量/统计优先），排名/GPA在构成优势时才写

## 三、消费业务型（管培生 / 快消 / 零售运营）

### 选材偏好
- 优先：市场与产品理解、消费者洞察、渠道/零售运营、销售与沟通、品牌sense
- 示例素材：`{电商/零售平台高频使用与品类运营感知}`、`{经济学供需/价格弹性分析框架}`、`{项目管理与跨团队协调}`、`{线下活动组织（规模数字）}`
- 加分：`{驾照（可出差/外勤）}`、`{普通话等级（沟通）}`
- 删减：复杂技术工具细节弱化，突出"人能沟通、业务能落地"

### 表达锚点
- 骨架：**结果/规模：关键动作 + 方法**
- 例："统筹N场活动覆盖N+人次，分工执行零差错，获{荣誉}"
- 强调规模数字、组织协调、结果交付；体现对消费者的同理心与市场敏感

### 版面注意
- 大厂管培岗可保留照片（职业形象岗）
- 实习bullet标题用"XX运营/消费者洞察"类JD语言
